# Review type: Report / analysis

Evaluate this report or analysis (for example, a sales report, a data analysis, a research summary, a status report) as a careful analyst and as the executive who will act on it. If source data is in the reference material, open it and check the figures. Check, in priority order:

1. **Numbers match the data**: spot-check totals, percentages, growth rates, rankings and date ranges against the source data. Report every mismatch as Critical, with both values. Note which figures you checked and which you could not.
2. **Conclusions are supported**: does each conclusion follow from the data shown? Watch for correlation presented as cause, cherry-picked periods, small samples, survivorship, and missing comparisons (vs. last period, target or benchmark).
3. **Methodology**: are the data source, time range, filters, definitions and exclusions stated? Would someone else get the same numbers?
4. **Executive summary**: does it state the key findings and the recommended action up front, in a few lines? Would a busy reader get the point without reading further?
5. **Missing analysis**: the obvious question a reader will ask that the report doesn't answer.
6. **Charts and tables**: right chart type for the comparison, labeled axes and units, honest scales, no clutter, consistent rounding.
7. **Recommendations**: specific, owned, and tied to the findings.
8. **Clarity**: jargon, undefined metrics, inconsistent terms.
